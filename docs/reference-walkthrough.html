Example root: /repo; source: /repo/docs/index.html, line 1. These are schematic absolute paths. The valid case targets the existing docs/assets/guide.css; the traversal uses an illustrative outside filename.

Valid encoded local URL

  1. href='assets/%67uide.css?rev=2#theme'HTMLReferences records non-null src and href attributes from start tags, with the source line for diagnostics.
  2. path = 'assets/%67uide.css'; query = 'rev=2'; fragment = 'theme'urlsplit(target.strip()) runs first. Scheme and network location are empty and path is nonempty, so this reference enters the local-path checks.
  3. unquote → assets/guide.css resolve → /repo/docs/assets/guide.cssDecode the path once with strict decoding, join to source.parent, then resolve. Query and fragment are not filename components. resolve() normalizes parent segments and follows symlinks.
  4. resolved.is_relative_to(/repo) → TrueThe resolved target is inside the resolved repository root. The boundary uses path ancestry, not a string-prefix comparison.
  5. resolved.exists() → True → continueThis reference passes and validation continues. That is not a whole-package PASS: other references and package checks can still fail. The theme fragment is not checked.

Encoded traversal rejection

  1. href='%2e%2e/%2e%2e/outside.css'The same HTML parser records this reference and its line. Encoding does not make a local reference trusted.
  2. path = '%2e%2e/%2e%2e/outside.css'; query = ''; fragment = ''There is no scheme or network location and the path is nonempty, so the local-path branch runs.
  3. unquote → ../../outside.css resolve → /outside.cssResolving /repo/docs/../../outside.css escapes /repo. Containment is evaluated after decoding and resolution.
  4. resolved.is_relative_to(/repo) → False require(False, …) → SystemExitReject immediately with “target escapes repository”. This is the failure boundary; the existence check is never reached, even if the outside target exists.
  5. FAIL: docs/index.html:1: href='%2e%2e/%2e%2e/outside.css': target escapes repositoryThe validator terminates at the first failing require. This last frame summarizes the rejection already raised at containment; it is not an additional executed check.
Source, limits and real validation

Grounded in source revision c939ba3ed42783bf6502d4562c4811e37116d1e7. Line references describe that revision; local file links open source files and do not promise line navigation.

  • scripts/validate.py: 19–21 (failure), 50–58 (collection), 61–80 (local references), 83–142 (package checks).
  • scripts/test_validate.py: 31–40 (encoded paths), 55–76 (traversal and symlinks), 78–115 (skips, HTML syntax and malformed paths).
  • README.md: portable validation command.

Only docs/index.html and docs/skill-map.html are scanned. This walkthrough is not automatically scanned. Only src/href attributes are collected; this is not a general HTML or CSS validator. References with a scheme, network location or empty path are skipped, not verified. No remote target or fragment ID is checked.

Splitting before decoding preserves encoded %23 and %3F as filename characters. Invalid local references caught as ValueError, OSError or RuntimeError fail with context. An in-root missing path fails with “missing local target”. An absolute path is treated as a filesystem path, not a web-root URL.

Run from the repository root for real local evidence:

python3 -B -m unittest discover -s scripts -p 'test_validate.py' -v
python3 -B scripts/validate.py

The first command runs isolated regression fixtures; the second checks the package, manifest, scanned HTML pages and synthetic fixtures. Neither playback nor these commands establish deployment evidence.
